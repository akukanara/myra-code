# @myralith/myra-responses-api-proxy

<p align="center"><code>npm i -g @myralith/myra-responses-api-proxy</code> to install <code>myra-responses-api-proxy</code></p>

This package distributes the prebuilt [Myra Responses API proxy binary](https://github.com/akukanara/myra-code/tree/main/codex-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/myra-responses-api-proxy.js --help
```

Refer to [`codex-rs/responses-api-proxy/README.md`](https://github.com/akukanara/myra-code/blob/main/codex-rs/responses-api-proxy/README.md) for detailed documentation.
